# CodeAlpha Data Analytics Internship — Task 3

## Data Visualization: Retail Sales Performance Analysis

This repository contains the Python implementation for Task 3. The project creates a synthetic retail-sales dataset and generates six visualizations:

1. Monthly Revenue Trend
2. Revenue by Product Category
3. Revenue Share by Region
4. Revenue by Day of Week
5. Unit Price Distribution by Category
6. Revenue Heatmap: Category vs Region

### Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Run
```bash
pip install pandas numpy matplotlib seaborn
python task3_data_visualization.py
```

The script creates `retail_sales_2024_2025.csv` and six PNG charts.

**Note:** The source report describes the dataset as synthetic. This script recreates a synthetic dataset and the analysis workflow; it is not the original hidden source dataset.
